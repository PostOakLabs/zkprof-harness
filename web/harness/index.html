zkprof-web harness

One Groth16/BN254 prover, two circuits to point it at — Merkle-Poseidon, and the SHA-256 preimage circuit csp-benchmarks measures — compiled to wasm32-unknown-unknown in two profiles, scalar and +simd128, run in your browser and reported as schema-valid JSON.

Deployment context

Read here, on the main thread, before anything is measured. The report carries its own copy of crossOriginIsolated; if the two disagree, the worked example is running in a context the report does not describe.

sha256 is a canonical circuit from csp-benchmarks, so a number measured here can be compared with that suite — and against the same circuit run natively by the CLI. That cross-target delta is the whole point of the tool.

One Poseidon permutation per level. 64 is 15,553 constraints. Setup is not measured, but it does cost time before the run starts.

The sizes csp-benchmarks measures under BENCH_INPUT_PROFILE=full. A size their exporter would reject is refused rather than measured.

Fixed witness, setup and prover randomness. Two runs are only comparable at the same seed and depth.
